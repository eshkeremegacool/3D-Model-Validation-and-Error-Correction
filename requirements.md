# Анализ требований проекта

## Цель
Разработать программу для автоматической проверки 3D-моделей, обнаружения геометрических ошибок и исправления поддерживаемых дефектов.

## Основные требования
- Загрузка 3D-моделей для проверки.
- Обнаружение выбранных геометрических ошибок.
- Автоматическое исправление поддерживаемых дефектов.
- Вывод результатов проверки.
- Тестирование программы на подготовленных моделях.

## Ожидаемый результат
Программа, которая помогает обнаруживать и исправлять ошибки 3D-моделей.
