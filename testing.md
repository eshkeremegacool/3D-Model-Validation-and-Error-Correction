# Контроль качества 3D-моделей

## Цель
Проверить работу программы для автоматического обнаружения и исправления ошибок 3D-моделей.

## Основные задачи
- Подготовить тестовые 3D-модели с ошибками и без них.
- Проверить правильность обнаружения геометрических дефектов.
- Проверить корректность автоматического исправления ошибок.
- Зафиксировать результаты тестирования.
- Выявить недостатки программы.

## Ожидаемый результат
Подтверждение корректности работы программы и список обнаруженных ошибок.
